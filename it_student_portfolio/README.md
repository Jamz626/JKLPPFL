# IT Student Portfolio

A simple responsive portfolio sample built with React, Vite, and CSS.

## Requirements
- Node.js (LTS recommended)
- npm

## Run locally
1. Extract the ZIP file.
2. Open the extracted `it_student_portfolio` folder in VS Code.
3. Open the VS Code terminal.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL shown in the terminal (usually http://localhost:5173).

## Build for deployment

```bash
npm run build
```

The production website will be generated in the `dist` folder.

## Customize
- Edit your name and introduction in `src/main.jsx`.
- Replace the sample projects and skills in `src/main.jsx`.
- Update the contact email in the `mailto:` link.
- Change colors and layout in `src/style.css`.

This is a starter sample. Replace all sample personal details before publishing.
